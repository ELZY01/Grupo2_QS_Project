# Changelog

Todas as alterações relevantes do StudyMatch serão documentadas neste ficheiro.

## [1.0.0] - 2026-11-27

### Adicionado
- Sistema de autenticação e gestão de contas.
- Gestão de estudantes e respetivos perfis académicos.
- Gestão de unidades curriculares e atribuições.
- Sistema de formação de grupos de estudantes.
- Regras de equilíbrio e estatísticas na formação de grupos.
- Testes automatizados para o backend e frontend.
- Documentação técnica, arquitetura e decisões de desenvolvimento.

### Melhorado
- Validação de dados através de Bean Validation.
- Cobertura de testes do backend.

### Tecnologias
- Java 21 e Spring Boot.
- Maven e Hibernate/JPA.
- PostgreSQL com Supabase.
- React e Vite.
- JUnit 5 e Vitest.
